## 📚 Learning Approach

I follow a practical, progressive learning approach:

1. **Learn** — Understand the concepts and underlying architecture.
2. **Plan** — Identify requirements, services, and security considerations.
3. **Implement** — Perform hands-on configurations in AWS.
4. **Validate** — Test functionality, permissions, and security.
5. **Document** — Record implementation steps, screenshots, and lessons learned.
6. **Publish** — Maintain a separate GitHub repository for each project.

---

## 🔐 Security-First Mindset

Cloud security is an essential part of this journey.

I aim to follow these principles throughout my projects:

- Apply the principle of least privilege.
- Enable Multi-Factor Authentication (MFA) wherever appropriate.
- Protect sensitive credentials and access keys.
- Avoid unnecessary public exposure of cloud resources.
- Understand and apply the AWS Shared Responsibility Model.
- Monitor resource usage and potential security risks.
- Follow secure configuration and cleanup practices.

**Security Note:** No passwords, access keys, secret keys, private keys, MFA codes, or other sensitive credentials will be committed to any public repository.
